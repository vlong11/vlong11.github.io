# Varisa Long — Portfolio

Static portfolio for https://vlong11.github.io/ with photos, a résumé, and two ANOVA school projects.

## Publish

Upload the contents of this folder to the root of `vlong11/vlong11.github.io`, preserving `images/` and `projects/`. In GitHub Settings → Pages, use the `main` branch and `/(root)`.

`index.html`, `style.css`, `images/`, `projects/`, and `resume.pdf` are included.

## File boundaries

Follow `AGENTS.md`: work only on relevant school, work, and portfolio files. Personal documents, especially government records, are outside the authorized scope. Originals in Downloads remain untouched.
